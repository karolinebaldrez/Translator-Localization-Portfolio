# 06 — AI Translation Evaluation

## 📌 Project Overview

This case study demonstrates a structured evaluation of an **AI-generated translation** from English into Brazilian Portuguese.

The objective is to evaluate not only grammatical correctness, but also semantic accuracy, fluency, terminology, localization, and overall usability.

---

## 🎯 Objective

The purpose of this evaluation is to determine whether an AI-generated translation is suitable for publication in a Brazilian Portuguese digital product.

The evaluation considers:

- Accuracy
- Fluency
- Terminology
- Localization
- Style and tone
- Cultural appropriateness
- Completeness
- User experience

---

# 6. Human Linguistic Review

An important part of AI translation evaluation is recognizing that a translation can be **technically correct but still require human review**.

In this example, the AI-generated translation successfully meets the evaluation criteria.

However, human review remains important because:

- Context may change the preferred terminology
- Product-specific glossaries may require different terminology
- Brand voice may require stylistic adjustments
- UI character limits may affect wording
- Different audiences may require different levels of formality

---

# 7. AI Translation Evaluation Framework

The following framework can be applied to future AI-generated translations.

### 1. Semantic Accuracy

Does the output preserve the original meaning?

### 2. Fluency

Does the translation sound natural to a native speaker?

### 3. Terminology

Does the output follow the approved terminology?

### 4. Localization

Does the content feel appropriate for the target market?

### 5. Style

Does the output follow the expected tone and brand voice?

### 6. Completeness

Was any information omitted, added, or distorted?

### 7. User Experience

Would the target audience understand and interact with the content naturally?

---

# 8. Error Taxonomy

AI-generated translations can contain several types of linguistic problems.

| Error Type | Description |
|---|---|
| Accuracy | Meaning is incorrectly transferred |
| Omission | Information from the source is missing |
| Addition | Information not present in the source is added |
| Mistranslation | Source meaning is incorrectly interpreted |
| Fluency | Target language sounds unnatural |
| Terminology | Incorrect or inconsistent terminology |
| Localization | Content is inappropriate for the target market |
| Style | Tone or register does not match the context |
| Grammar | Grammatical or syntactic errors |

---

# 9. Human vs. AI Evaluation

A high-quality AI translation workflow should not treat AI output as automatically correct.

Instead:

**AI Translation → Human Review → Error Detection → Scoring → Correction → Final Approval**

This workflow combines the speed of AI with human linguistic expertise.

---

# 🏆 Final Assessment

The evaluated AI translation achieved a **35/35 score** and is considered suitable for publication in the evaluated context.

However, the evaluation also demonstrates why **human linguistic QA remains valuable in AI-assisted translation workflows**.

AI can produce fluent and accurate translations, but quality depends on:

**Context + Terminology + Localization + Human Evaluation**
